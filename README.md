## Адаптивна модель поверхні фону Гатоса–Пратікакіса

Історичні манускрипти мають значні просторові варіації яскравості, у темному куті документа фон темніший, ніж чорнило в добре освітленому центрі. Класичні глобальні методи, такі як наприклад Оцу, у таких умовах відсікають половину тексту або залишають чорні плями. Модель же Гатоса моделює невидиму поверхню чистого паперу B(x,y) і приймає рішення на основі динамічної різниці B(x,y) - I(x,y).

### Оригінальний пайплайн за статтею
Вхідне зображення (в градаціях сірого) --> Wiener filter --> Sauvola`s adaptive thresholding --> Interpolation --> Examine pixel contrast --> Post-processing --> Вихідне зображення

1. Фільтр Вінера на основі локальної дисперсії згладжує плоскі фонові ділянки, але не розмиває перепади на межах літер.
2. Алгоритм Сауволи швидко розбиває пікселі на кандидатів у текст та ті що точно фон.
3. Для пікселів, позначених як текст, яскравість фону інтерполюється на основі навколишніх фонових пікселів (створюється віртуальний аркуш паперу на якому немає тексту).
4. Обчислюється середня глибина штрихів, та піксель класифікується як текст.
5. Операціями над зв'язними компонентами видаляється дрібне сміття, а морфологічне закриття склеює розірвані штрихи.

## Базова праця Гатоса–Пратікакіса–Перантоніса
1. Gatos, B., Pratikakis, I., & Perantonis, S. J. (2006). Adaptive degraded document image binarization. Pattern Recognition, 39(3), 317–327.

# Опис Метрик

### 1. Середньоквадратична помилка (MSE — Mean Squared Error)
* Базова метрика похибки, що використовується для кількісного вимірювання накопиченого відхилення інтенсивностей пікселів на кожній проміжній стадії відносно оригіналу.
* **Формула:**
  $$\text{MSE} = \frac{1}{M \cdot N} \sum_{x=0}^{M-1} \sum_{y=0}^{N-1} [I(x, y) - I'(x, y)]^2$$
* **Опис змінних:**
  * $M, N$ — висота та ширина зображення в пікселях;
  * $I(x, y)$ — значення яскравості пікселя еталонного/початкового зображення в точці з координатами $(x, y)$, де $I \in [0, 255]$;
  * $I'(x, y)$ — значення яскравості пікселя відновленого/обробленого зображення в точці $(x, y)$.
* **Значення:** $\text{MSE} = 0.0$ свідчить про абсолютну тотожність зображень. Чим менше значення MSE, тим точніше збіг. Недолік — показник чутливий до однакового глобального зсуву освітлення по всьому полю.

---

### 2. Пікове відношення сигналу до шуму (PSNR — Peak Signal-to-Noise Ratio)
* Стандартна метрика оцінки ступеня деградації сигналу. Вимірює логарифмічне співвідношення між максимально можливою динамічною енергією сигналу та енергією спотворювального шуму (помилки MSE), виражене в децибелах (дБ).
* **Формула:**
  $$\text{PSNR} = 10 \cdot \log_{10}\left(\frac{\text{MAX}_I^2}{\text{MSE}}\right)$$
* **Опис змінних:**
  * $\text{MAX}_I$ — максимально можлива яскравість для даного формату даних (для 8-бітних $\text{MAX}_I = 255$);
  * $\text{MSE}$ — середньоквадратична помилка між двома масивами;
  * Граничний випадок: якщо $\text{MSE} = 0.0$ (повний збіг), $\text{PSNR} \to \infty$ (у коді зафіксовано як константа $999.0$ дБ).
* **Значення:** Чим вище значення PSNR, тим менше стороннього шуму додано в результаті обробки. Для півтонових зображень значення $\ge 30$ дБ свідчить про хорошу якість, а $\ge 40$ дБ — про майже непомітну похибку.

---

### 3. Індекс структурної подібності (SSIM — Structural Similarity Index Measure)
* Оцінка візуальної якості з урахуванням сприйняття людською зоровою системою (HVS). На відміну від MSE, вона реагує не на зміну освітлення, а на деградацію ліній та структури тексту. Вимірює подібність трьох складових зображення: яскравості, контрасту та структурну кореляцію.
* **Формула:**
  $$\text{SSIM}(x, y) = \frac{(2\mu_x\mu_y + C_1)(2\sigma_{xy} + C_2)}{(\mu_x^2 + \mu_y^2 + C_1)(\sigma_x^2 + \sigma_y^2 + C_2)}$$
* **Опис змінних:**
  * $\mu_x, \mu_y$ — середні значення яскравості зображень $x$ та $y$ (оцінка світлоти);
  * $\sigma_x^2, \sigma_y^2$ — дисперсії яскравості (оцінка контрастності зображень);
  * $\sigma_{xy}$ — взаємна коваріація між $x$ та $y$ (оцінка збігу форм і контурів);
  * $C_1 = (K_1 \cdot L)^2$ та $C_2 = (K_2 \cdot L)^2$ — стабілізаційні константи, які запобігають діленню на нуль, якщо знаменник наближається до нуля;
  * $L = 255$ (динамічний діапазон), $K_1 = 0.01$, $K_2 = 0.03$ (константи за замовчуванням, звідки $C_1 = 6.5025$, $C_2 = 58.5225$).
* **Значення:** Значення лежить у діапазоні $[-1.0, 1.0]$. Значення $1.0$ означає 100% збереження структури літер.

---

### 4. F-Measure (FM — Гармонійне середнє за стандартом DIBCO)
* Головна еталонна метрика міжнародних конкурсів бінаризації DIBCO / H-DIBCO. Оцінює якість виділення тексту відносно бінарного еталона Ground Truth. Вимірює баланс між повнотою виявлення символів та чистотою відсікання фону.
* **Формули:**
  $$\text{FM} = \frac{2 \cdot \text{Recall} \cdot \text{Precision}}{\text{Recall} + \text{Precision}} \times 100\%$$
  $$\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}}, \quad \text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}}$$
* **Опис змінних:**
  * $\text{TP}$ (True Positive) — пікселі тексту, які алгоритм правильно визначив як чорнило;
  * $\text{FP}$ (False Positive) — пікселі чистого паперу, які алгоритм помилково зафарбував чорнилом (шум, волокна);
  * $\text{FN}$ (False Negative) — пікселі справжнього тексту, які алгоритм помилково стер (розриви букв);
  * Конвенція для документів: Текст = $0$ (чорний), Фон = $255$ (білий).
* **Значення:** Виражається у відсотках $[0\%, 100\%]$. Що вищий показник FM, то точніше відновлено документ без викривлення гліфів.

---

### 5. Pseudo F-Measure ($F_{ps}$)
* Модифікована версія F-Measure, розроблена спеціально для оцінки якості бінаризації документів. Метрика суворіше штрафує за втрату центральних пікселів літер, ніж за незначні нерівності на краях штрихів.
* **Формули:**
  $$F_{ps} = \frac{2 \cdot R_{ps} \cdot P_{ps}}{R_{ps} + P_{ps}} \times 100\%$$
  $$R_{ps} = \frac{\sum_{(x, y) \in \text{TP}} W_R(x, y)}{\sum_{(x, y) \in \text{TP}} W_R(x, y) + \sum_{(x, y) \in \text{FN}} W_R(x, y)}, \quad P_{ps} = \frac{\text{TP}}{\text{TP} + \sum_{(x, y) \in \text{FP}} W_P(x, y)}$$
* **Опис змінних:**
  * $R_{ps}, P_{ps}$ — зважені псевдо-повнота (pseudo-Recall) та псевдо-влучність (pseudo-Precision);
  * $W_R(x, y) \in [0.5, 1.0]$ — вагова карта пікселів еталона $\text{GT}$: центральні пікселі штриха мають максимальну вагу $1.0$, а контурні краї — $0.5$;
  * $W_P(x, y) \in [1.0, 2.0]$ — вагова карта для фонових помилок: у зоні біля контуру символів $\text{GT}$ вага підвищена в межах $(1.0, 2.0]$, а за її межами дорівнює $1.0$;
  * $\text{TP}, \text{FP}, \text{FN}$ — істинно позитивні, хибно позитивні та хибно негативні пікселі тексту.
* **Значення:** Виражається у відсотках $[0\%, 100\%]$. Що ближче значення до $100\%$, то краще збережена топологічна структура символів для подальшого розпізнавання тексту.

### 6. Міра спотворення на основі оберненої відстані (DRD — Distance Reciprocal Distortion)
* Спеціалізована метрика візуальних дефектів бінарних документів, що корелює зі сприйняттям спотворень людським оком. Враховує відстань від кожного помилкового пікселя до найближчих правильних пікселів символу: чим далі помилковий піксель від контуру літери або чим сильніше він розриває лінію, тим вищий штраф.
* **Формули:**
  $$\text{DRD} = \frac{\sum_{k=1}^{S} \text{DRD}_k}{\text{NUBN}}$$
  $$\text{DRD}_k = \sum_{i=-2}^{2} \sum_{j=-2}^{2} |\text{GT}(i, j) - B_k(x, y)| \cdot W_{Nm}(i, j)$$
  $$W_m(i, j) = \begin{cases} 0, & i = 0, j = 0 \\ \frac{1}{\sqrt{i^2 + j^2}}, & \text{інакше} \end{cases}, \quad W_{Nm}(i, j) = \frac{W_m(i, j)}{\sum_{i=-2}^{2} \sum_{j=-2}^{2} W_m(i, j)}$$
* **Опис змінних:**
  * $S$ — загальна кількість розбіжних (інвертованих) пікселів між бінарним результатом $B$ та еталоном $\text{GT}$;
  * $\text{DRD}_k$ — зважене спотворення $k$-го помилкового пікселя з координатами $(x, y)$;
  * $\text{NUBN}$ (Non-Uniform 8x8 Blocks Number) — кількість неоднорідних блоків розміром $8 \times 8$ у зображенні еталона $\text{GT}$ (тобто блоків, які не є повністю білими чи повністю чорними);
  * $W_{Nm}(i, j)$ — нормована матриця ваг розміром $5 \times 5$, елементи якої обернено пропорційні евклідовій відстані до центра.
* **Значення:** $\text{DRD} \ge 0.0$. Чим значення ближче до $0.0$, тим чистіший документ і тим менше візуально помітних розривів чи плям.

### 7. Агрегований показник якості DIBCO (Avg-Score)
* Зведена рейтингова оцінка якості алгоритмів бінаризації документів, що об'єднує всі чотири офіційні метрики конкурсів DIBCO/H-DIBCO ($\text{FM}$, $F_{ps}$, $\text{PSNR}$, $\text{DRD}$) в єдиний підсумковий бал.
* **Формула:**
  $$\text{Avg} = \frac{\text{FM} + F_{ps} + \text{PSNR} + (100 - \text{DRD})}{4}$$
* **Опис змінних:**
  * $\text{FM}$ — класична F-міра у відсотках;
  * $F_{ps}$ — псевдо F-міра у відсотках;
  * $\text{PSNR}$ — пікове відношення сигналу до шуму між результатом і еталоном (у дБ);
  * $\text{DRD}$ — міра візуального спотворення на основі оберненої відстані.
* **Значення:** Що вищий бал $\text{Avg}$, то краща загальна якість відновлення документа. Результати $\text{Avg} \ge 80\text{–}85$ балів вважаються високим показником на складних історичних рукописах.

### 8. Негативна метрика помилок (NRM — Negative Rate Metric)
* Спеціалізована метрика, яка дозволяє з'ясувати причину падіння якості: чи алгоритм стирає літери, чи засмічує фон. Вимірює рівномірне середнє між коефіцієнтом втрати тексту ($NR_{FN}$) та коефіцієнтом фонового шуму ($NR_{FP}$).
* **Формули:**
  $$\text{NRM} = \frac{NR_{FN} + NR_{FP}}{2}$$
  $$NR_{FN} = \frac{\text{FN}}{\text{TP} + \text{FN}}, \quad NR_{FP} = \frac{\text{FP}}{\text{TN} + \text{FP}}$$
* **Опис змінних:**
  * $\text{TN}$ (True Negative) — пікселі чистого паперу, які алгоритм правильно залишив білим фоном;
  * $NR_{FN}$ (False Negative Rate / Втрата деталей) — частка втрачених справжніх штрихів від усієї площі тексту;
  * $NR_{FP}$ (False Positive Rate / Помилковий шум) — частка фону, заляпана паразитним шумом (наприклад фіксує бруд від надмірної сітки CLAHE).
* **Значення:** Діапазон $[0.0, 1.0]$. Ідеальне значення $\text{NRM} = 0.0$. Дозволяє точно налаштувати поріг $q$ у стадії 4 для досягнення балансу.

---

### 9. Коефіцієнт збереження меж (EPI — Edge Preservation Index)
* Оцінює збереження гостроти контурів літер без потреби в еталоні Ground Truth. Вимірює статистичну кореляцію між просторовими градієнтами (високочастотними перепадами яскравості) вхідного та обробленого зображень.
* **Формула:**
  $$\text{EPI} = \frac{\sum_{x, y} (\Delta I_1(x, y) - \overline{\Delta I_1}) \cdot (\Delta I_2(x, y) - \overline{\Delta I_2})}{\sqrt{\sum_{x, y} (\Delta I_1(x, y) - \overline{\Delta I_1})^2 \cdot \sum_{x, y} (\Delta I_2(x, y) - \overline{\Delta I_2})^2}}$$
* **Опис змінних:**
  * $I_1$ — вихідна яскравість документа;
  * $I_2$ — оброблене бінарне зображення;
  * $\Delta I(x, y) = |I(x+1, y) - I(x, y)| + |I(x, y+1) - I(x, y)|$ — матриця величини локальних градієнтів за двома просторовими осями;
  * $\overline{\Delta I_1}, \overline{\Delta I_2}$ — середнє арифметичне градієнтів відповідних матриць.
* **Значення:** Значення лежить у діапазоні $[0.0, 1.0]$. Якщо фільтри розмивають штрихи літер або CLAHE створює хибні градієнти на волокнах — EPI падає. Значення, близькі до 1.0, підтверджують різкість і чіткість контурів.

---

### 10. Індекс стабільності до шуму (NSI — Noise Stability Index)
* Перевіряє здатність конвеєра видавати однаковий результат при виникненні адитивного шуму матриці сканера. Вимірює міру схожості за Жаккаром (Intersection over Union, IoU) між бінарним текстом, виділеним зі штатного зображення, та текстом, отриманим після штучного зашумлення оригіналу.
* **Формула:**
  $$\text{NSI} = \frac{|T_{\text{clean}} \cap T_{\text{noisy}}|}{|T_{\text{clean}} \cup T_{\text{noisy}}|}$$
* **Опис змінних:**
  * $T_{\text{clean}}$ — множина пікселів тексту (зі значенням 0), виділена пайплайном зі звичайного документа;
  * $T_{\text{noisy}}$ — множина пікселів тексту, отримана тим самим пайплайном після внесення в яскравість документа нормального шуму $\mathcal{N}(0, \sigma^2)$ із $\sigma = 5$ при фіксованому генераторі `seed=42` (згідно з вимогами ТЗ);
  * $\cap$ — кількість спільних пікселів тексту (перетин);
  * $\cup$ — загальна кількість пікселів, позначених як текст хоча б в одному з прогонів (об'єднання).
* **Значення:** Діапазон $[0.0, 1.0]$. Якщо $\text{NSI} \ge 0.90$, пайплайн вважається високостабільним і стійким до шумів.


# Інструкція зі встановлення та запуску

### 1. Системні вимоги та залежності
* Встановлений інтерпретатор **Python 3.10** або новішої версії.
* Необхідні сторонні бібліотеки:
  ```bash
  pip install numpy pillow
  ```

---

### 2. Структура вхідних даних перед запуском
Перед стартом переконайтеся, що файли розміщені у відповідних папках:
* `dataset/` — початкові графічні файли (`.bmp`, `.png`, `.jpg`, `.tif`, `.tiff`).
* `gt/` — бінарні еталони Ground Truth (з тими самими іменами або суфіксом `_gt`, необов'язково для роботи пайплайну, але необхідно для підрахунку метрик точності бінаризації FM та NRM).

---

### 3. Запуск автоматизованого пайплайну
Для запуску повної обробки всієї вибірки з генерацією покрокових зображень та звітів:
```bash
python pipeline.py
```

**Процес виконання:**
1. Програма знаходить усі зображення у `dataset/`.
2. Для кожного зображення послідовно виконує 5 стадій:
   * `Стадія 1`: Локальне вирівнювання контрасту (CLAHE).
   * `Стадія 2`: Адаптивна бінаризація Сауволи.
   * `Стадія 3`: Реконструкція поверхні чистого фону паперу.
   * `Стадія 4`: Контрастна динамічна класифікація.
   * `Стадія 5`: Морфологічне звуження та розширення.
3. У директорії `processed/<ім'я_файлу>/` зберігаються:
   * Копія оригіналу (`original.*`) та еталона (`gt.*`).
   * Проміжні зрізи кожної стадії (`stage0_lum.png` ... `stage5_shrink_swell.png`).
   * Фінальний відновлений документ (`final.png`).
   * Локальна динаміка метрик по стадіях (`metrics.csv`).
4. У корені `processed/` створюється підсумковий файл `summary_metrics.csv` з усіма розрахованими метриками по всій вибірці.

---

### 4. Запуск модульних автотестів
Для швидкої перевірки правильності роботи алгоритмів на матриці $5 \times 5$ та верифікації граничних випадків:

python -m unittest tests.py
