Для аналізу та реставрації історичних документів, стародруків і рукописів обрано дві доволі відомі наукові моделі, які розв'язують наступні проблеми:

1. **Фотометрична реставрація та адаптивна бінаризація**  
   Базується на праці Гатоса–Пратікакіса–Перантоніса. Вона вирішує проблему фотометричної деградації, де на фото видно нерівномірне вицвітання чорнил, локальні тіні, перепади освітлення, старіння волокон пергаменту.
   
3. **Спектрально-текстурне розділення та просторово-геометрична нормалізація**  
   Базується на роботах Тонацціні щодо розділення наскрізного чорнила та Шукли щодо геометричного вирівнювання нахилу. Вона вирішує проблему структурної деградації, де видно просочування чорнила зі зворотної сторінки, текстура пористого матеріалу та перекіс рядків.

## Адаптивна модель поверхні фону Гатоса–Пратікакіса

Історичні манускрипти мають значні просторові варіації яскравості, у темному куті документа фон темніший, ніж чорнило в добре освітленому центрі. Класичні глобальні методи, такі як наприклад Оцу, у таких умовах відсікають половину тексту або залишають чорні плями. Модель же Гатоса моделює невидиму поверхню чистого паперу B(x,y) і приймає рішення на основі динамічної різниці B(x,y) - I(x,y).

### Оригінальний пайплайн за статтею
Вхідне зображення (в градаціях сірого) --> Wiener filter --> Sauvola`s adaptive thresholding --> Interpolation --> Examine pixel contrast --> Post-processing --> Вихідне зображення

1. Фільтр Вінера на основі локальної дисперсії згладжує плоскі фонові ділянки, але не розмиває перепади на межах літер.
2. Алгоритм Сауволи швидко розбиває пікселі на кандидатів у текст та ті що точно фон.
3. Для пікселів, позначених як текст, яскравість фону інтерполюється на основі навколишніх фонових пікселів (тобто по факту створюється віртуальний аркуш паперу на якому немає тексту).
4. Обчислюється середня глибина штрихів, та піксель класифікується як текст.
5. Операціями над зв'язними компонентами видаляється дрібне сміття, а морфологічне закриття склеює розірвані штрихи.

### Реалізація
У Лабораторній роботі №5 ми вже реалізували фільтр Вінера, тому для попередньої обробки ми використовуємо CLAHE. Він так само адаптивно бореться з локальними перепадами яскравості, але працює через локальне вирівнювання гістограм.

## Спектрально-текстурне розділення та геометричний аналіз перекосу

Другою типова проблема архівів є просочування чорнила зі зворотної сторінки та перекошення аркуша при скануванні. Чорнило зворотного боку має схожу оптичну густину з лицьовим, тому фотометричні моделі, такі як модель поверхні фону Гатоса–Пратікакіса, помилково сприймають його за основний текст. Проте воно має інший колірний спектр та текстуру, крім того, нахил рядків не дозволяє коректно сегментувати слова й рядки. Дана ж модель нормалізує орієнтацію та фізичну текстуру сторінки.

### Оригінальний пайплайн за дослідженнями Тонацціні та Шукли
Оригінальна наукова модель складається з 5 послідовних стадій:

Вхідне кольорове зображення --> Spectral / Color Decorrelation --> Texture Feature Extraction --> Edge / Zero-Crossing Detection --> Skew Angle Detection --> Geometric Transformation --> Вихідне зображення

1. Проекція у колірний простір, де канал насиченості та відтінку відділяє блідо-руде зворотне чорнило від свіжого вугільно-чорного лицьового.
2. Оцінка матриці взаємної появи сірого (GLCM), оскільки пори паперу й розмите наскрізне чорнило мають іншу локальну ентропію та контраст, ніж чіткі межі шрифту.
3. Використання оператора другої похідної (LoG) для виявлення замкнених контурів справжніх літер через переходи через нуль.
4. Перетворення Хафа акумулює нормальні координати уздовж ліній рядків для знаходження глобального кута нахилу документа.
5. Поворот усього поля документа на знайдений кут для повернення сторінки в горизонтальне положення.

### Реалізація
У лабах був лише оператор Робертса та матриця яскравості, тому ми беремо оператор Марра–Гілдрет, текстурний аналіз GLCM та перетворення Хафа з афінним поворотом.

| Стадія в пайплайні | Метод для реалізації | Категорія | Функція методу |

| 2 | Обчислення текстурної матриці суміжності (GLCM) | Категорія 6: Аналіз текстур | Будує матрицю просторової суміжності сірого, обчислюючи локальну карту контрасту й однорідності паперу. |
