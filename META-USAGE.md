# Декларація використання інструментів генеративного ШІ

## Застосовані інструменти
* Модель / Інструмент: Велика мовна модель Gemini-flash-lite(3.5) у режимі інтерактивного діалогу.
* Сфера застосування: Консультації щодо оптимізації математичних операцій у NumPy, форматування формул метрик у LaTeX, генерація модульних тестів і допоміжного коду вводу-виводу даних.

---

## Ключові запити та завдання

Під час виконання проєкту ШІ-асистенту ставилися такі ключові завдання та промпти:

1. Векторизація та оптимізація алгоритмів:
   * Промпт: Як переписати розрахунок метрики зі стандарту DIBCO 2016 на NumPy за допомогою двовимірної згортки замість попіксельного циклу по кожному пікселю, щоб оптимізувати обчислення?
   * Промпт: Як замінити ковзне вікно для підрахунку фонових сусідів у стадії інтерполяція фону Гатоса та стадії Shrink & Swell на двовимірні інтегральні зображення зі сталою складністю?

2. Модульне тестування:
   * Промпт: Склади юніт-тести для tests.py на матрицях 5х5 пікселів для всіх 5 стадій пайплайну, де очікувані значення будуть зашитими матрицями що я надав, порахованими аналітично, щоб уникнути повторення формул у тестах.
   * Промпт: Напиши тести для перевірки крайових ситуацій критерію де є файл розміром 0 байт, файл із пошкодженим бінарним заголовком, обробка RGBA-прозорості та неквадратні розміри матриці як наприклад 4х13.

3. Допоміжний код та документування:
   * Промпт: Реалізуй клас ImageIO для збереження підсумкових результатів у форматі CSV та зчитування L-каналу простору LAB за допомогою Pillow.
   * Промпт: Переведи математичні формули з оригінальних статей Gatos et al. (2006) та H-DIBCO 2016, що я надав, у формат розмітки LaTeX для опису метрик у README та звіті.

## Згенеровані та адаптовані фрагменти

1. metrics.py:
   * Методи підрахунку метрик DIBCO за наданими формулами зі статей.

2. tests.py:
   * Каркас тестів на основі стандартного модуля unittest.TestCase.
   * Модульні тести на обробку крайніх варіантів як 0 байт, битий заголовок, формат RGBA.

3. image_io.py:
   * Код запису списку результатів у файл CSV.

4. README.md:
   * Текстові формули метрик у форматі LaTeX за наданими формулами.

## Процес валідації, критичний аналіз та доопрацювання автором

Згенерований ШІ код не приймався безпосередньо, а піддавався верифікації та ручному редагуванню:

1. Виправлення тавтологічності тестів:
   Первинно згенерований ШІ варіант тестів містив генерацію очікуваного масиву тією ж самою формулою що і методи з алгоритмів. Даний недолік було виявлено і замінено вирази на константні задані матриці.
2. Оптимізація типів даних і стабільність:
   Першочергові тести крайніх варіантів спричиняли аварійне завершення програми через ділення на 0 та нульову дисперсію, через що було додано захист, перевірку на нульові дисперсії у монохромних зображеннях (np.maximum(..., 1e-6)) та було перевірено досягнення оцінки Pylint 10.00/10.00 без жодного зауваження статичного аналізатора.
